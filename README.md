# 📊 SQL — Learning & Practice

Repositorio dedicado a mi aprendizaje práctico de **SQL**, siguiendo el curso gratuito [SQL Ultimate Course](https://github.com/DataWithBaraa/sql-ultimate-course) de **Data With Baraa**.

## 🎯 Objetivos de aprendizaje

- Dominar consultas SQL para extraer y filtrar información.
- Relacionar y combinar datos de diferentes tablas.
- Aplicar funciones de agregación y cálculos sobre conjuntos de datos.
- Comprender subconsultas, CTEs y funciones de ventana.
- Validar datos con SQL.
